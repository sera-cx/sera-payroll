# The original prototype

`sera-payroll-prototype.html` is the single-file working prototype that this repository was built from. Open it in a browser: the Employer, Employee and Operator views run entirely in memory with sample data, and the "Build notes" button renders the original brief (also ported to [docs/BUILD_NOTES.md](../BUILD_NOTES.md)). It is the reference for behaviour and layout. Where the real build and the prototype disagree, the prototype shows the intent and the code in `packages/core` is the rule.
